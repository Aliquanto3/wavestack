# Charte de messagerie d'Exemplia, version 2 (2026)

<!-- Texte fictif rédigé pour WaveStack. Exemplia est une organisation imaginaire : cette charte ne décrit aucune entreprise réelle. -->

Cette version remplace la version 1 depuis le 1er janvier 2026, à la suite du changement de fournisseur de messagerie décrit dans la note de changement associée : c'est la version en vigueur.

La messagerie professionnelle reste réservée à un usage professionnel, mais un usage personnel occasionnel et raisonnable est désormais toléré, par exemple un message bref à caractère privé. Chaque message, avec ses pièces jointes, peut désormais atteindre 25 Mo grâce au nouveau fournisseur ; au-delà, un lien de partage temporaire reste nécessaire.

Les messages sont conservés 3 ans dans la boîte de messagerie avant archivage, contre 1 an dans la version précédente : ce changement répond à une obligation de conservation du secteur. Un message supprimé par erreur peut être restauré par le support dans les 30 jours, comme auparavant.

Un message envoyé par erreur à un mauvais destinataire externe reste signalé à la cellule de réponse aux incidents dans l'heure, surtout s'il contient des informations confidentielles ou des données personnelles.

La redirection automatique vers une adresse personnelle reste interdite, de même que l'usage d'une messagerie personnelle pour un échange professionnel.
