# E-Mail-Richtlinie von Exemplia, Version 2 (2026)

Diese Version ersetzt Version 1 seit dem 1. Januar 2026, nach dem in der zugehörigen Änderungsmitteilung beschriebenen Wechsel des E-Mail-Anbieters: Dies ist die aktuell gültige Version.

Das berufliche Postfach bleibt der beruflichen Nutzung vorbehalten, doch eine gelegentliche und angemessene private Nutzung wird nun geduldet, zum Beispiel eine kurze private Nachricht. Jede Nachricht kann mit ihren Anhängen dank des neuen Anbieters nun bis zu 25 MB groß sein; darüber hinaus bleibt ein temporärer Freigabelink erforderlich.

Nachrichten werden 3 Jahre im Postfach aufbewahrt, bevor sie archiviert werden, gegenüber 1 Jahr in der vorherigen Version: Diese Änderung entspricht einer Aufbewahrungspflicht der Branche. Eine versehentlich gelöschte Nachricht kann wie bisher vom Support innerhalb von 30 Tagen wiederhergestellt werden.

Eine versehentlich an einen falschen externen Empfänger gesendete Nachricht wird weiterhin innerhalb einer Stunde dem Reaktionsteam für Vorfälle gemeldet, besonders wenn sie vertrauliche Informationen oder personenbezogene Daten enthält.

Die automatische Weiterleitung an eine private Adresse bleibt verboten, ebenso die Nutzung eines privaten Postfachs für einen beruflichen Austausch.
