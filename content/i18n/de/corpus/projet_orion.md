Dieses Sentinel-Dokument dient Demonstrationen zum Löschen eines Dokuments aus dem Korpus (Story 14): Es trägt einen leicht erkennbaren Inhalt, der nach Entfernung des Dokuments vollständig aus einer Suche verschwinden muss.

Projekt Orion ist ein fiktives internes Projekt von Exemplia, gekennzeichnet durch den einmaligen Code ORN-7731-QZ. Dieser Code erscheint in keinem anderen Dokument des Korpus: Seine Anwesenheit oder Abwesenheit in einer Suche erlaubt es, eindeutig zu prüfen, ob dieses Dokument tatsächlich aus dem Index gelöscht wurde.

Solange dieses Dokument inaktiv bleibt, erscheint es in keinem Index, keinem Suchauszug und keinem Fingerabdruck des aktiven Korpus. Nach der Aktivierung für die Demonstration muss eine Suche nach dem Code ORN-7731-QZ es finden; nach seiner Löschung darf dieselbe Suche es nicht mehr finden, weder im Index noch in einer vom Harness aufbewahrten Spur.

Dieses Dokument enthält keine weiteren Informationen: Es beschreibt weder ein echtes Projekt noch eine echte Person noch echte Daten von Exemplia.
