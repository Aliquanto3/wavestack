# Exemplia email charter, version 2 (2026)

<!-- Fictitious text written for WaveStack. Exemplia is an imaginary organisation: this charter describes no real company. -->

This version replaces version 1 as of 1 January 2026, following the change of email provider described in the associated change note: this is the version in force.

The professional mailbox remains reserved for professional use, but an occasional and reasonable personal use is now tolerated, for example a brief private message. Each message, with its attachments, can now reach 25 Mo thanks to the new provider; beyond that, a temporary sharing link is still needed.

Messages are kept for 3 years in the mailbox before archiving, against 1 year in the previous version: this change answers a retention obligation of the sector. A message deleted by mistake can be restored by support within 30 days, as before.

A message sent by mistake to the wrong external recipient is still reported to the incident response team within the hour, especially if it contains confidential information or personal data.

Automatic forwarding to a personal address remains forbidden, as is using a personal mailbox for a professional exchange.
